Privacy policy

Minimal Machines Publisher · last updated 4 October 2026

Minimal Machines Publisher ("the tool") is a command-line program that uploads videos to the Minimal Machines YouTube channel. It is operated by the channel owner, Paul de Bruijn ("we"), and is used only by us, on our own computer, for our own channel. This page explains what data the tool touches and what happens to it.

Who uses the tool

One person: the owner of the Minimal Machines channel. The tool is not distributed to, or usable by, anyone else. No accounts are created and no visitors to this website are tracked.

What Google data the tool accesses

The tool signs in to Google with OAuth and requests the scope https://www.googleapis.com/auth/youtube.force-ssl. With that permission it:

  • reads the signed-in account's YouTube channel name and ID, to confirm which channel it will upload to;
  • reads the list of videos already on that channel, to avoid uploading a duplicate;
  • uploads video files and sets their title, description, tags, category, thumbnail, privacy status, and scheduled publish time;
  • adds uploaded videos to a playlist on the same channel;
  • posts a comment on the channel's own videos.

It does not read, store, or process any data about viewers, subscribers, or other YouTube users. It does not access Gmail, Drive, Contacts, or any Google service other than YouTube.

What the tool stores

  • OAuth tokens. After sign-in, Google issues an access token and a refresh token. The tool saves them in a file named token.json on the owner's computer, readable only by the owner's user account. They are used to call the YouTube API on later runs without signing in again.
  • Upload records. After each upload the tool writes the YouTube video ID, title, and scheduled time to a local file so it can avoid uploading the same video twice.

Nothing is stored on a server. Nothing is sent anywhere except to Google's YouTube API endpoints.

Sharing

We do not share, sell, or transfer any Google user data to third parties. No analytics, advertising, or tracking services are involved. The only recipient of data is Google, through the YouTube Data API, for the purpose of publishing videos to our own channel.

Retention and deletion

Tokens stay on the owner's computer until deleted. To delete them, remove token.json. To revoke the tool's access to the Google account entirely, visit myaccount.google.com/permissions and remove "Minimal Machines Publisher". Revoking access invalidates the stored tokens immediately.

Google API Services User Data Policy

The tool's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements. Data obtained through Google APIs is used only to provide the upload function described above and for no other purpose.

This website

This site is static HTML hosted on GitHub Pages. It sets no cookies and runs no scripts of ours. GitHub may log standard web server data (such as IP addresses) under GitHub's privacy statement.

Changes

If the tool's behaviour changes, this page changes with it, and the date at the top is updated.
